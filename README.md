# Sistem Input & Rekap Data Nilai Siswa (CLI)

Aplikasi Command Line Interface (CLI) berbasis Python untuk manajemen pencatatan data akademik siswa, penghitungan nilai rata-rata otomatis (Bahasa Inggris, Matematika, Fisika), pencarian data, serta penyimpanan persisten berbasis file.

---

## Fitur Utama

- **Pencatatan Data Siswa**: Input nama lengkap, kelas, serta nilai mata pelajaran pokok.
- **Kalkulasi Rata-Rata Otomatis**: Menghitung bobot rata-rata akademik secara instan.
- **Tabel Rekapitulasi Rapi**: Menampilkan seluruh data siswa dalam format tabel baris dan kolom yang terstruktur di terminal.
- **Pencarian Cepat**: Cari data siswa berdasarkan nama dengan pencocokan fleksibel.
- **Penyimpanan Persisten**: Seluruh data otomatis tersimpan dan dimuat kembali saat aplikasi dibuka.

---

## Prasyarat

- Python 3.8 atau versi lebih baru (tidak membutuhkan library eksternal, hanya menggunakan modul bawaan Python).

---

## Cara Menjalankan

1. Kloning repositori:
   ```bash
   git clone https://github.com/IlhamXkyo/input-data-siswa.git
   cd input-data-siswa
   ```

2. Jalankan program:
   ```bash
   python data_siswa.py
   ```

3. Gunakan navigasi menu angka pada terminal untuk menginput atau melihat rekap data.
